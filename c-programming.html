Pre-increment (++x) vs Post-increment (x++)
  • Pre-increment (++x): "Change, then use." The variable is increased by 1 before it is evaluated in the current expression.
  • Post-increment (x++): "Use, then change." The current value of the variable is evaluated in the expression first, and it is increased by 1 afterward.

Example:

int a = 5, b = 5;
int y = ++a; /* Pre-increment: 'a' becomes 6, then 'y' is assigned 6 */
int z = b++; /* Post-increment: 'z' is assigned 5, then 'b' becomes 6 */
Type Conversion (Implicit vs Explicit)
  • Implicit Conversion (Coercion): Done automatically by the compiler. A smaller data type is safely promoted to a larger one (e.g., an int mixed with a double becomes a double).
  • Explicit Conversion (Type Casting): Forced manually by the programmer using a cast operator, like (float) or (int), placed directly in front of the variable or value.

Division Behavior:

  • int / int: Performs integer division. It completely truncates (drops) any decimal part.
    Example: 5 / 2 evaluates to 2.
  • double / int: The int is implicitly promoted to a double before calculation, preserving the decimal.
    Example: 5.0 / 2 evaluates to 2.5.

Common Pitfalls & Errors:

  • Unintended Integer Division: Writing float ans = 5 / 2; gives 2.000000 because the integer division evaluates to 2 before it is assigned to the float. Fix it by casting at least one side: float ans = (float)5 / 2;.
  • Data Loss (Demotion): Assigning a floating-point number to an integer variable drops the fractional part entirely without rounding. Writing int x = 3.99; stores exactly 3 in memory, permanently losing the .99.
Bitwise Shift Operators (<< and >>)

These operators manipulate the raw binary bits of an integer directly in memory.

  • Left Shift (<<): Shifts all bits to the left by a specified number of positions, adding zeros on the right.
    Mathematical Effect: Multiplies the number by 2 for every single shift.
    Example: 3 << 1 (Binary 0011 shifts left to become 0110, which equals 6 in decimal).
  • Right Shift (>>): Shifts all bits to the right, discarding the rightmost bits that fall off the edge.
    Mathematical Effect: Divides the number by 2 (acting as integer division) for every single shift.
    Example: 8 >> 2 (Binary 1000 shifts right twice to become 0010, which equals 2 in decimal).
Bitwise NOT (~) and Two's Complement

In modern systems, C uses two's complement representation for signed integers. Because of this architecture, applying the bitwise NOT operator (~)—which flips all 0s to 1s and 1s to 0s in binary—results in a direct mathematical shortcut.

Formula: ~x = -(x + 1)

Examples:

  • Positive Integer: If x = 5, applying ~5 evaluates to -(5 + 1). The result is -6.
  • Negative Integer: If x = -10, applying ~(-10) evaluates to -(-10 + 1), which is -(-9). The result is 9.
Operator Precedence & Associativity

Most C operators evaluate Left to Right. The only three groups that evaluate Right to Left are Unary, Ternary, and Assignment.

  6. Equality == !=
  7. Bitwise & then ^ then |

Random Numbers & String Conversion
  • atof(): Converts a string (ASCII) to a floating-point number (double). Requires <stdlib.h>.
  • rand(): Generates a pseudo-random integer between 0 and RAND_MAX. Requires <stdlib.h>.
  • srand(): Seeds the random number generator. If you don't seed it, rand() produces the exact same sequence of numbers every time you run the program.
  • time(NULL): Returns the current system time in seconds. Passing this into srand() guarantees a unique starting point for randomness every single time the code runs. Requires <time.h>.

Code Example:

#include <stdio.h>
#include <stdlib.h> /* Required for atof, rand, srand */
#include <time.h>   /* Required for time */

int main() {
    /* 1. Using atof() to convert text to a double */
    char text[] = "98.6";
    double temp = atof(text);
    printf("Converted string to double: %.2lf\n", temp);

    /* 2. Seeding the random number generator with current time */
    srand(time(NULL));

    /* 3. Using rand() to get a random number between 0 and 99 */
    int random_num = rand() % 100;
    printf("Random number (0-99): %d\n", random_num);

    return 0;
}
Strings and the Null Terminator (\0)

In C, strings are character arrays that are read until a null terminator (\0) is found. Standard functions like printf() will stop printing the moment they encounter the first \0, even if there is more text after it.

#include <stdio.h>

int main() {
    /* The array holds: 'H','e','l','l','o','\0','W','o','r','l','d','\0' */
    char x[] = "Hello\0World";
    
    printf("%s\n", x);

    return 0;
}

Output:

Hello
  • Explanation: While the array x successfully stores the entire sequence (taking up 12 bytes in memory), the %s format specifier stops reading exactly after "Hello" because it detects the explicit null character you placed in the middle.
Format Specifier Width (%8d and %-8d)
  • Minimum Width, Not Maximum: %8d tells printf() to reserve a minimum field width of 8 characters. It does not restrict the number to 8 digits.
  • Overflow Handling: If the integer is longer than the specified width, printf() simply expands the field and prints the entire value. For example, printing 123456789 with %8d outputs all 9 digits without truncating anything.
  • Alignment: By default, numbers are right-aligned (padded with empty spaces on the left). Adding a minus sign like %-8d forces the number to be left-aligned (padded with spaces on the right).

Code Example:

#include <stdio.h>

int main() {
    /* Right-aligned, padded with 6 spaces */
    printf("[%8d]\n", 12);       
    
    /* Left-aligned, padded with 6 spaces on the right */
    printf("[%-8d]\n", 12);      
    
    /* Value exceeds 8 chars; prints the whole number */
    printf("[%8d]\n", 123456789); 

    return 0;
}

Output:

[      12]
[12      ]
[123456789]
Bubble Sort Algorithm

Bubble sort works by repeatedly stepping through the list, comparing adjacent elements, and swapping them if they are in the wrong order. The process is repeated until the array is sorted.

Code Implementation:

/* Note: SIZE must be defined globally or via a macro, e.g., #define SIZE 10 */

void bubbleSort(int a[]) {
    int pass, j, hold;
    
    /* Outer loop controls the number of passes */
    for(pass = 1; pass <= SIZE - 1; pass++) {
        
        /* Inner loop performs the comparisons and swaps */
        for(j = 0; j <= SIZE - 2; j++) {
            
            /* If the current element is greater than the next, swap them */
            if(a[j] > a[j + 1]) {
                hold = a[j];
                a[j] = a[j + 1];
                a[j + 1] = hold;
            }
        }
    }
}
Binary Search Algorithm

Binary search is a highly efficient algorithm for finding an item from a sorted array. It works by repeatedly dividing the search interval in half until the target value is found or the interval is empty.

Code Implementation:

/* Note: The array MUST be sorted before using Binary Search */

int binarySearch(int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;

    while (left <= right) {
        /* Calculates mid this way to prevent integer overflow */
        int mid = left + (right - left) / 2; 

        /* Check if target is present at mid */
        if (arr[mid] == target) {
            return mid; /* Element found, return its index */
        }
        
        /* If target is greater, ignore the left half */
        if (arr[mid] < target) {
            left = mid + 1;
        }
        /* If target is smaller, ignore the right half */
        else {
            right = mid - 1;
        }
    }
    
    /* Target was not found in the array */
    return -1; 
}
